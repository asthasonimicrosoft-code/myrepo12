# EcoSphere — DevChallenge Website

A responsive sustainability landing page built with plain HTML, CSS, and JavaScript.

## Features
- Modern, responsive layout for desktop, tablet, and mobile
- Animated-feel CSS planet illustration (no image assets required)
- Mission, impact statistics, and challenge sections
- Challenge category filters
- Interactive challenge completion with progress bar
- Saves progress in the browser with `localStorage`
- Mobile navigation, accessible status announcements, and reduced-motion support

## Run locally
1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension, or run `python -m http.server 8000` in the folder and visit `http://localhost:8000`.

## Files
- `index.html` — page structure and content
- `style.css` — styling, responsive layouts, and planet illustration
- `script.js` — filters, challenge completion, progress state, and mobile menu

## Demo data note
The community totals and environmental estimates are illustrative demo figures, not independently measured results. This is a front-end prototype; it does not use a backend or user accounts.
